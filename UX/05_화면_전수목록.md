## 4. 공통 규칙
- 왼쪽 메뉴 너비: 프로젝트 안 화면 296, 전역 화면 264. 1024 폭에서는 각각 248과 232
- 머리글 검색칸: 너비 640으로 고정하고 좌우 묶음 폭을 같게 두어 로그인 전후 위치가 같다
- 모바일 360: 하단 탭바(홈, 찾기, 알림, 내 프로젝트)
- 모드: 밝은 화면, 어두운 화면, 선명한 화면 모드를 변수 모드로 전환한다. 사본 프레임을 만들지 않는다
