## 3. 파일 종류 아이콘 대응 (fileIcon.js)

- 프로젝트 150, 49, 13의 파일 행에서 실제 svg 이름과 우리 img 이름을 비교(이름 기준). 일치 확인한 샘플: .gitignore=git, AGENTS.md=markdown, CHANGELOG*.md=markdown, CITATION.cff=file, LICENSE=certificate, NOTICE=file, README.md=markdown, SECURITY.md=markdown, demo.gif=image, package.json=nodejs, package-lock.json=nodejs, server.json=json, tsconfig.json=json, tsup.config.ts=typescript, 사용법.md=markdown, image.png=image, index.html=html, vite.config.js=javascript, download_openfiscaldata_test.py=python, .gitattributes=git. 총 20종 이상, 불일치 0건
- 폴더 아이콘: 실제는 svg 이름 'folder'. 우리 폴더 아이콘은 이 측정에서 img가 아닌 svg로 나와 이름 비교를 못 했다(스크린샷에서는 둘 다 윤곽 폴더). 4절 항목 확인 필요
- 경로가 둘인 폴더(.github/workflows, plugins/kordoc, .Codex/plans): 실제는 한 행에 합쳐서 표시, 우리는 이름이 같은 행으로 존재 확인 불가(측정 도구가 이름으로 찾지 못함)
