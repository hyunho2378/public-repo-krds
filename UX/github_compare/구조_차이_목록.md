## 이번 빌드에서 바꾼 것
- 제목 줄(저장소 이름, 관심 표시, 써 봤어요)은 저장소 홈에서만 나옴. 이슈 목록 등은 탭 줄 바로 아래에서 시작.
- "정보" 버튼은 탭 줄 오른쪽 끝으로 이동.
- 파일 보기 막대: 미리보기/코드/Blame과 줄 수, 크기가 왼쪽, 원본/복사/이력이 오른쪽.
- 상세 화면 경로 줄은 "이슈 / #번호", "변경 기록 / 해시"처럼 소유자/저장소를 뺀 한 줄(머리글 경로가 소유자/저장소를 보여 줌).
- data-figma 이름표: 머리글 경로 `repo-path`, 본문 경로 줄 `breadcrumb`.
