# 03. 커밋 목록과 상세 (Commits, Commit detail)

- 대상: github.com/microsoft/vscode/commits/main/, /commit/HEAD (1440x900)
- 우리 대응 화면: R-04 변경 기록, R-05 커밋 상세

## 1. 커밋 목록 구조
- 날짜별로 묶여 있음("Commits on Oct 30, 2026" 같은 소제목)
- 한 줄: 작성자 아바타, 커밋 메시지(링크, 굵게), 작성자 이름, 짧은 해시(클립보드 복사), 상대 시간
- 측정: 한 줄 높이 69px, 글자 14px

## 2. 커밋 상세 구조
- 머리: 커밋 메시지(제목), 본문 설명, 작성자/커미터 아바타와 이름, 부모 커밋 링크, 전체 해시(복사), "Browse files" 버튼
- 변경 파일 수와 +추가/-삭제 합계(상단 요약)
- 파일마다 접기 머리(+/- 수, 파일 경로), Split/Unified 전환, 파일별 코드 보기 바로가기
- diff 줄: 번호 두 칸(이전/이후), 추가는 녹색 배경 +, 삭제는 빨강 배경 -
- 측정: diff 줄 글자 14px/줄높이 24px(파일 보기 화면의 12px/20px보다 큼)

## 3. 우리 화면(R-04, R-05) 대응
- 구조는 이미 비슷하게 구현됨(날짜 묶음, 통합/나란히 전환, 줄 번호 두 칸)
- 확인 필요: 우리 diff 줄 글자 크기가 코드 보기(D2Coding) 크기와 같은지, 아니면 GitHub처럼 diff에서 한 단계 크게 쓰는지 결정 필요(제안: 코드 가독성 우선이면 통일, GitHub 흉내면 분리)
- 커밋 목록 한 줄 69px은 우리 커밋 막대/목록과 비교 측정이 아직 없음 — 다음 작업에서 실측
