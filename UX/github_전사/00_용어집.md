# GitHub·GitLab 용어 한국어 대응표

- 작성일: 2026. 10. 30.
- 원칙(UX/07_밀도_문구_기준.md 5장): 개발 용어는 원래 이름을 한글로 그대로 쓴다. 공공 깃랩 한국어 원문이 있으면 그것을 우선한다. 낯선 용어는 옆이나 툴팁에 짧은 풀이를 보조 글자로 붙인다. 가운뎃점과 이모지는 쓰지 않는다.
- 출처 표시: [깃랩]=공공 깃랩 실제 한국어 화면 원문, [영어]=GitHub 원문을 우리가 번역

| 영어 원문 | 공공 깃랩 원문 | 우리 용어 | 풀이(처음 보는 사람용) | 출처 |

## 우리 서비스 전용 추가 용어(공공 깃랩·GitHub에 없음)
| 용어 | 뜻 |
|---|---|
| 업무로 찾기 | 업무를 문장으로 입력해 관련 도구를 찾는 기능 |
| 공개 준비 점검 | 올리기 전 README, 보안 파일, 실행 안내 등을 자동으로 확인하는 기능 |
| 써 봤어요 | 이 도구를 실제로 써 본 기관이 기록을 남기는 기능 |
| 실행 환경 | 이 도구를 바로 웹에서 쓸 수 있는지, 설치가 필요한지 안내 |
