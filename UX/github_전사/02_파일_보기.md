# 02. 파일 보기 (Blob view)

- 대상: github.com/microsoft/vscode/blob/main/package.json (1440x900)
- 우리 대응 화면: R-03 파일 보기

## 1. 영역 구조
1. 경로(Breadcrumb): 소유자 / 저장소 / 저장소 전환(아이콘) / 폴더... / 파일명
2. 도구 줄(오른쪽): 줄 수와 용량, 원본 보기(Raw), 복사(Copy raw content), 다운로드(Download raw file), 편집(연필, 로그인 필요), 더보기(...)
3. 코드 보기/Blame 전환 탭
4. 코드 본문: 줄 번호(클릭하면 해당 줄 주소로 이동, 범위 선택 가능), 구문 강조, 가로 스크롤
5. 오른쪽: 별도 정보 패널 없음(About은 저장소 홈에만 있음)

## 2. 전체 글
| 위치 | 영어 원문 | 우리 번역 |
|---|---|---|
| 도구 | Raw | 원본 보기 |
| 도구 | Copy raw content | 복사 |
| 도구 | Download raw file | 내려받기 |
| 도구 | Edit file | 편집 |
| 도구 | Delete file | 삭제 |
| 탭 | Code | 코드 |
| 탭 | Blame | 작성자 보기 |
| 바로가기 안내 | Switch repository (option shift r) | 저장소 전환(옵션+시프트+R) |

## 3. 측정값
| 요소 | 값 |
|---|---|
| 코드 줄 글자 | 12px, 줄 높이 20px, monospace(ui-monospace, SFMono-Regular, SF Mono, Menlo, Consolas 등) |
| 줄 번호 폭 | 내용 자릿수에 따라 가변, 본문과 같은 글꼴 |

## 4. 상태
- 로그인 전: 편집, 삭제 버튼이 보이지만 누르면 로그인 요구(비활성 표시는 아니고 클릭 시 이동)
- 큰 파일: "This file is too large to display" 영역이 생기고 Raw로 유도. 일정 크기 넘으면 구문 강조를 끔
- 이진 파일: "Binary file not shown" 문구
- 이미지 파일: 이미지 자체를 렌더, 확대/축소 없음
- 마크다운 파일(.md): 기본은 렌더된 미리보기, "Code" 탭 눌러야 원문 마크다운

## 5. 우리 화면(R-03) 대응과 차이
- 있음: 경로, 코드/미리보기/작성자 보기 전환, 줄 번호, 구문 강조, 원본/복사/내려받기/변경 기록
- 다름
  1. 코드 글자 12px/줄높이20px 대 우리 측정 필요(D2Coding 적용 크기를 20px 줄 높이에 맞춰야 함) — 코드 갈래에 전달함
  2. GitHub 줄 번호는 클릭하면 그 줄 주소(#L12)로 이동하고 Shift 클릭으로 범위 선택. 우리 구현 범위 확인 필요
  3. GitHub는 파일 보기 화면에 별도 안내문(쉬운 설명, 용어 풀이)이 없음. 우리는 오른쪽에 "쉬운 설명", "용어 풀이"를 추가로 두는데, 이것이 UX/07의 "개발 플랫폼 기본 + 공무원 덧붙임" 원칙에 맞음. 단, 덧붙임이 코드 영역 폭을 줄이면 안 됨(이미 지시됨)
  4. "편집" 버튼이 로그인 전 우리 화면에서 아예 안 보이는지, GitHub처럼 보이되 누르면 로그인 요구인지 확인 필요(GitHub 방식 권장: 버튼은 보이고 누르면 로그인)
