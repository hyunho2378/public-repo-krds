# 밀도 측정표 (1차, 직접 실측)

- 작성일: 2026. 10. 30.
- 측정 환경: 1440x900, GitHub(microsoft/vscode, 로그인 상태), 우리 배포(https://hyunho2378.github.io/public-repo-krds/projects/150)
- 방법: `getComputedStyle`, `getBoundingClientRect()`로 실제 렌더값 측정. 캡처: shots/github_vscode_1440.png, shots/our_r01_1440.png
- 상태: 1차 직접 측정(작업자 도구 장애로 주 작업자가 직접 쟀다). 작업자 기능이 복구되면 화면별 전사와 함께 더 많은 요소를 추가 측정한다

## 핵심 차이

| 요소 | GitHub 실측 | 우리 실측 | 차이 | 판정 |
|---|---|---|---|---|
| 저장소 제목 글자 크기 | 32px / 600 | 24px / 700 | 작음(좋음) | 유지, 굵기만 600으로 |
| 파일 표 한 행 높이 | 40px | 51px | +11px (1.28배) | 40px 목표 |
| 파일 이름 글자 크기 | 14px | 17px | +3px | 14~15px 목표(KRDS body/small 14px) |
| 1440x900에서 보이는 파일 행 수 | 16~20줄 | 8줄 | 절반 이하 | 행 높이와 글자 줄이면 자연히 늘어남 |
| 사이드바 항목 높이 | (GitHub 저장소에는 왼쪽 사이드바 없음, 비교 불가) | 54px | — | KRDS 사이드 메뉴 작은 변형 기준 32px 목표 |
| 머리글 높이 | 100px(조직 배너 포함, 저장소 자체 툴바만은 더 작음) | 66px | — | 66px는 과하지 않음. 유지 |
| 본문 기본 글자 | 14px | 17px(body 기본값) | +3px | 본문 전역 15px 이하로 낮추는 안 검토 |

## 2차 실측 (탭 줄, 버튼, 사이드바, 커밋 막대)

| 요소 | GitHub 실측 | 우리 실측 | 차이 |
|---|---|---|---|
| 상단 탭(코드/이슈/PR 등) 한 칸 | 높이 32px, 글자 14px/400 | 높이 31px, 글자 15px/700(굵음) | 높이는 비슷, 굵기가 너무 셈 |
| 저장소 관심·팔로우류 버튼 | 높이 28px, 글자 12px/500 | 높이 38px, 글자 17px/700 | 버튼이 1.35배 큼, 글자 1.4배 큼 |
| 마지막 커밋 막대 | 높이 28px, 글자 12px | (별도 측정 전) | 참고용 |
| 사이드바 메뉴 버튼(자주 쓰는 메뉴 등) | 비교 대상 없음(GitHub 저장소에는 이런 왼쪽 메뉴가 없음, 공공 깃랩 구조) | 높이 38px, 글자 17px/700 | 공공 깃랩 실측과 비교 필요(과제로 남김) |

| 코드 보기 줄 글자 | 12px, 줄높이 20px, monospace(ui-monospace 계열) | D2Coding 사용(크기 미측) | 우리 코드 보기 줄 높이도 20px까지 줄여야 함 |

| 커밋 목록 한 줄 높이 | 69px, 글자 14px | 미측 필요(R-04) | 참고 |
| diff(변경 내용) 줄 글자 | 14px, 줄높이 24px(blob 보기와 다름, 더 큼) | 미측 필요(R-05) | 커밋 상세 diff는 파일 보기보다 글자가 조금 큼 |

## 해석
- 가장 큰 문제는 **파일 표 행 높이(51 vs 40)와 파일 이름 글자 크기(17 vs 14)**다. 이 둘만 고쳐도 한 화면에 보이는 파일 수가 8줄에서 16줄 안팎으로 늘어나 GitHub와 비슷해진다
- 저장소 제목은 오히려 우리가 더 작아서 문제가 아니다. 다만 글자 굵기가 700(KRDS heading)인데 GitHub는 600이다
- 본문 기본 글자가 17px인 것이 전체 밀도를 끌어올리는 원인으로 보인다. KRDS body/small(14px 근처 단계)을 표와 목록에 적극 써야 한다

## KRDS 변수 환산 후보
- 행 높이 40px → KRDS 간격 변수 중 `number-13`(40) 또는 `padding-6`+글자 높이 조합. 정확한 토큰명은 krds_tokens.css에서 확인 필요
- 파일 이름 글자 14px → KRDS 글자 스타일 `body/small`(일반적으로 14px 단계). Typography 페이지 변수명으로 교체
- 사이드바 항목 목표 32px → KRDS `side_navigation` 작은 변형이 있으면 그것, 없으면 `number-8`(32) 패딩으로 구성
