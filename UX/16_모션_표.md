## 2. '틱틱 끊김' 원인과 고친 것
| 원인(이전 코드) | 고친 것 |
|---|---|
| 사이드바를 접으면 컴포넌트를 아예 그리지 않음(App.jsx 조건부 렌더링) → 다시 펴면 DOM을 새로 만들고 본문 격자 열이 240 → 0으로 한 번에 바뀜 | 사이드바는 늘 그려 두고 `transform: translateX(-100%)`로 밀어 넣음. 본문 판은 `margin-left`를 같은 200ms 곡선으로 이동(D-22 2장). 숨긴 동안은 inert + visibility hidden(초점 안 감) |
| 묶음 목록도 조건부 렌더링(펼치면 목록이 한 번에 생김) | 목록을 늘 그리고 `grid-template-rows: 0fr ↔ 1fr` + opacity 200ms |

| 채운 삼각형 꺾쇠(KRDS chevron_down) | 얇은 KRDS arrow-down(›, ⌄) 16, 회전 120ms. audit:code '채운 삼각형' 검사 추가 |

## 4. 그 밖의 인터랙션(코드)
- 메뉴와 드롭다운: 8 위로 올라오며 opacity 200ms(Menu 부품 공통), Esc와 바깥 클릭으로 닫힘, 닫히면 버튼으로 초점(기존 Menu)
- 툴팁: 400ms 뒤 opacity 120ms, 초점에서도 열림, Esc 닫힘
- 페이지 이동: 상단 바와 사이드바는 그대로, 본문(.rb-page)만 opacity 120ms
- 목록 행, 파일 표 행: 호버 회색 면 120ms
- 사이드바 항목: 호버 120ms, 눌림 pressed 면, 초점 링 2px, 현재 항목은 전환 없이 즉시
- 단축키: / 검색, ? 단축키 목록 대화상자, g c / g i / g p, t 파일 찾기, b 사이드바(파일 보기에서는 파일 트리), y 고정 주소
- 남은 것: 토스트(작업 결과), 메뉴 닫힘 애니메이션(지금은 즉시 닫힘), 스크롤 위치 복원 확인, 더보기 높이 전환

## 5. 클릭할 때 화면이 튕기는 문제 (2026. 10. 31. 0시대 사용자 지적, 배포본 1440 x 900 측정)
- 측정: 클릭 직후 2초 동안 requestAnimationFrame마다 제목(#main h1) 위치, 본문(#main) 높이, 바닥글 위치, scrollY, 본문 글자 수, 보이는 스켈레톤을 기록. CLS는 layout-shift(입력 직후 제외)
- 원인
  1. 같은 화면에서 조건만 바뀌어도(탭, 필터, 정렬) useData가 상태를 Loading으로 되돌려 목록이 스켈레톤으로 바뀌고 본문 높이가 2130 → 381로 무너졌다가 다시 커짐(바닥글이 위아래로 튐)
  2. 화면 이동(사이드바)마다 새 화면이 스켈레톤부터 그려짐(캐시 없음, 2~3프레임), 본문 opacity 120ms 페이드로 깜빡임
  3. 본문 높이가 이동 순간 줄어 바닥글이 올라왔다 내려감
- 고친 것: 조건 변경 때 이전 내용 유지(새 자료가 오면 바꿈), 정적 모드 공개 자료 2분 메모리 캐시, 화면 이동 순간(그리기 전) 본문 높이를 이전 높이로 700ms 유지, 본문 페이드 제거, 스켈레톤은 160ms 넘게 걸릴 때만 표시
- 서비스 워커는 쓰지 않음(등록 해제). 버전 확인(version.json)은 화면에 돌아올 때와 5분마다만 돌고 새 배포가 있을 때만 다시 불러온다(클릭과 무관)
