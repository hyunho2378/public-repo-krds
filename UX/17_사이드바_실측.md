- 측정: 2026. 10. 31. 18:10~18:40, https://gitlab.aigov.go.kr (비로그인, 읽기 전용). 탐색 사이드바 `/explore/projects`, 프로젝트 사이드바 `/chrisryugj/kordoc`

- 결과: 1280, 1440, 1920에서 사이드바 안 값은 모두 같다(폭이 바뀌어도 사이드바는 고정 240)
- 회귀 검사: `app/scripts/sidebar-spec.json`(이 표의 숫자) + `sidebar-inspect.js`(화면 안 검사, 1px 이내) + `check-sidebar.mjs`(경로·폭·상태 돌기, `npm run check:sidebar`) + `audit-sidebar-tokens.mjs`(토큰 값 정적 검사, `npm run audit:code`에 포함)

## 2. 묶음 펼침과 접힘(프로젝트 사이드바, 1440)

- 고정됨: 펼침이 기본. 접으면 머리만 남고 다음 줄(추가 기능)이 바로 30 아래. 펼친 안쪽 항목은 머리 다음 30 간격
- 묶음 8개(관리, 계획, 코드, 빌드, 배포, 운영, 모니터, 분석): 접힘이 기본, 피치 30. 펼치면 안쪽 항목이 30 간격으로 머리 아래에 붙고 다음 묶음은 그 아래 30
- 예: 코드 펼침 → 머지 리퀘스트, 리포지토리, 브랜치, 커밋, 태그, 리포지토리 그래프, 리비전 비교, 스니펫(각 28, 피치 30)
- 우리: 같은 피치. 접힌 묶음에 남던 2px(접힌 목록의 위 안쪽 여백)를 없앴다

## 5. 남긴 차이와 이유

- 글자 14 → 15: KRDS 글자 단계(13, 15, 17, 19)에 14가 없다. 15가 13보다 1 가깝다
- 서랍 기준 1200 → 768: 코드의 미디어 질의는 KRDS 구간(768, 1024, 1280)만 쓴다(audit-code). 1024~1279에서 실제는 서랍, 우리는 펼침
- 접음 상태의 옆 펼침 메뉴: 아직 없다. 묶음 아이콘을 누르면 사이드바를 펼친다
- 뒤 덮개 0.64 → 0.75: KRDS 모달 딤 값 그대로
