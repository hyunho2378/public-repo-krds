# 09 README 렌더 점검

- 점검일: 2026. 10. 30. 커밋 7455722
- 비교 대상: GitHub `chrisryugj/kordoc` 저장소 화면의 README(1440x900, 어두운 화면)와 우리 배포본 `/projects/150`의 README 상자. 원문은 `sample/kordoc/api/readme_raw.md`(170줄)와 같은 내용이다
- kordoc README에 없는 기능(접기, 체크리스트, 중첩 목록, 정렬 표, 앵커, HTML 일부)은 시험용 원문 한 편을 직접 써서 GitHub 마크다운 API(`api.github.com/markdown`, gfm 모드)가 돌려준 HTML과 우리 화면(이슈 작성 미리보기)을 같은 원문으로 나란히 비교했다. 시험 원문에는 지어낸 내용이 아니라 형식 확인용 글자만 있고, 어떤 저장소에도 올리지 않았다
- 스크린샷: 현재 세션 `tmp/`의 repl-display 이미지(GitHub 화면 2장, 우리 화면 4장)로 직접 확인했다

## 1. 원인 (점검 전)
- 이전 `Readme.jsx`는 줄 단위로만 처리했다. 표(`| a | b |`)는 글자 그대로, 코드 블록은 본문에서 떼어 "개발자용 명령어 보기"로 접고, 목록은 문단으로, 중첩 목록과 `<details>`, 체크리스트, 제목 앵커는 없었다. 그림은 모두 설명 글자만 남겼고 HTML 태그는 지웠다
- 마크다운 라이브러리와 sanitize 설정은 없었다(`package.json` 의존성은 react, react-router-dom만). 외부 라이브러리를 새로 넣지 않고 해석기를 직접 썼다

## 2. 바뀐 구조
- `app/src/components/Help/mdparse.js`: 마크다운 원문을 노드 목록(데이터)으로 해석한다. 블록(제목, 문단, 인용, 목록, 표, 코드, details, align, 가로선)과 인라인(굵게, 기울임, 취소선, 코드, 링크, 그림, HTML 일부)
- `app/src/components/Help/Markdown.jsx`: 노드를 React 요소로 그린다. `innerHTML`, `dangerouslySetInnerHTML`을 쓰지 않으므로 HTML을 문자열로 꽂는 길이 없고 sanitize 대상도 없다. 링크는 `http`, `https`, `mailto`, 저장소 안 상대 경로, 문서 안 `#`만 열고 `javascript:`, `data:`는 글자로만 남긴다
- 그림: 저장소 상대 경로는 `프로젝트 주소/-/raw/기본 브랜치/경로`로 불러온다. 같은 서버 주소 그림도 열린다. 그 밖의 서버 그림(배지)은 설명 글자 알약으로 바꾼다(외부 요청 차단, 이전 설계 유지)
- 표: KRDS 표 부품(`krds-table-wrap`, `tbl data`), 머리 13 굵게, 본문 15, 행 최소 40, 정렬(`:--`, `:-:`, `--:`) 반영, 칸이 길면 줄바꿈, 폭이 모자라면 표 상자 안에서 가로 스크롤
- 원문에 없는 내용은 만들지 않는다. 처리하지 못하는 HTML은 태그만 지우고 안의 글자를 남긴다

## 4. 확인 결과 요약
- kordoc README: 표 3개(2x7, 3x11, 3x5)가 표로 그려지고, 코드 블록 5개와 목록, 인용, 큰 그림이 GitHub 화면과 같은 순서로 나온다. 다른 점은 배지(글자 대체), 제목 구분선 없음, 표 테두리 모양이다
- 시험 원문 한 편(제목, 링크, 서식, 인용, 중첩 목록, 체크리스트, 순서 목록, 가로선, 코드 블록, 정렬 표, details, 가운데 정렬, 그림과 배지): 모두 의도대로 그려짐. 두 화면을 같은 원문으로 나란히 봤다
- 검사: 표 머리 13/700, 행 40 최소, 코드 13, 표 상자 가로 스크롤 동작, 복사 버튼 상태 표시("복사함"), 접힘 동작, 제목 앵커 이동 시험을 직접 확인했다

## 5. 남은 일
- `> [!NOTE]` 알림 블록, 표 밖 HTML, 수식, mermaid, 각주는 미지원이다. 필요하면 노드 종류를 추가한다
- 배지 그림을 보이게 할지는 외부 요청 차단 정책과 맞바꾸는 결정이라 사용자 판단이 필요하다
- 이슈와 변경 제안 본문에서는 저장소 틀이 없어 상대 경로 그림과 링크가 글자로 남는다
