## 탭 줄 이름(RepoTabs)
코드, 작업 항목, 머지 리퀘스트, 파이프라인, 위키, 분석, 설정(관리 권한), 더보기, 사용 방법(덧붙임, 맨 끝). 풀이는 title로만.

## 덧붙임(공공 깃랩에 없는 이름, 사유)
| 이름 | 사유 |

| 사용 기록 | 공무원이 도구를 써 본 기관을 남기는 덧붙임 기능 |
| 사용 방법 | 내 PC에서 쓸 수 있는지, 따라 하기 단계를 보여 주는 덧붙임 탭 |
| 업무로 찾기 | 업무 문장으로 도구를 찾는 검색 덧붙임 |
| 공개 준비 점검 | 올리기 전 README/보안 파일 확인 덧붙임 |
| 실행 환경 | 웹/설치/다운로드 판정 배지 덧붙임 |

## 검사
`npm run audit:code`의 check-copy가 copy/ko.js, copy/ui.js, api/static.js, server/src에서 금지 용어(관심 표시, 써 봤어요, 변경 제안, 작업 갈래, 변경 기록, 가입, 이슈(이슈 보드 제외))를 찾아 0건이어야 통과한다.

## 확인 안 된 것
- 파일 목록의 "이름/최근 커밋/최근 업데이트" 머리글은 공공 깃랩 원문(gitlab/02 캡처)과 한 번 더 대조해야 한다.
- 별표 항목이 공공 깃랩 화면에서 정확히 "별표"로 보이는지는 캡처 파일로 확인하지 못했다(README 1절에 별표 기록은 "프로젝트 홈 제목+공개 배지, 별표").
