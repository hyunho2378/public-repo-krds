# 장식 요소 점검 (사용자 원칙: UI는 GitHub, KRDS, 공공 깃랩에 있는 것으로, 우리 기능은 덧붙임)

- 작성일: 2026. 10. 30.
- 방법: 코드에서 점, 알약(rb-pill), 배지, 상자, 글자 상자(kbd), 개수 표시를 찾아 근거(GitHub, GitLab, KRDS, 덧붙임)를 적고, 근거가 없으면 제거했다. 화면 확인은 브라우저를 쓸 수 있을 때 한 번 더 한다(이번 작업 중 브라우저 창이 끊겨 CSS/코드 근거만 확인)

| 요소 | 위치 | 근거 | 조치 |
|---|---|---|---|
| 공지 앞 노란 점 | 로그인 공지 | 근거 없음(공공 깃랩 로그인 공지는 제목/날짜/내용 목록) | 제거, 제목 굵게 + 날짜 13 |
| 점검 결과 앞 상태 점 | 도구 올리기, 공개 준비 점검 | 근거 없음 | 제거(글자만), CSS 규칙도 삭제 |
| 언어 색 점(회색) | 목록 메타 | GitHub 언어 점, 색은 KRDS 회색으로 이미 정함 | 유지 |
| 저장소 "공개" 알약 | 저장소 홈 제목 | GitHub Public 라벨, 공공 깃랩 공개 배지 | 유지 |
| 토픽 알약 | 정보 영역 | GitHub topics | 유지 |
| 브랜치 "기본/보호됨" 알약 | 브랜치 표 | 공공 깃랩 브랜치 목록 배지(기본값, 보호됨) | 유지 |
| 릴리스 "최신" 알약 | 릴리스 목록 | GitHub Latest 라벨 | 유지(한 줄 고정) |
| 이슈/MR 상태 알약(열림/닫힘/반영됨) | 상세 제목 아래 | GitHub 상세의 Open/Closed 라벨 | 유지. 목록 행의 상태 알약은 이미 제거(상태 전환 탭이 대신함) |
| 라벨 알약 | 작업 항목 목록/상세 | GitHub/GitLab 라벨 | 유지 |
| 탭 줄 개수(작업 항목) | RepoTabs | GitHub 탭 Counter | 유지 |
| 상태 전환의 개수 알약 | 작업 항목/머지 리퀘스트 목록 머리, 브랜치 탭 | GitHub는 "Open 130" 숫자만 | 알약 배경 제거, 숫자만 |
| "B" 키 글자 상자 | 파일 트리 단추, 커밋 상세 | GitHub는 툴팁/메뉴 안에서만 표시 | 단추 안 kbd 제거, title과 aria-keyshortcuts로 이동 |
| 이미지 불러오기 실패 알약 | README 이미지 | GitHub는 대체 글자만 표시 | 알약 테두리 제거, 글자만 |
| 실행 환경 배지(웹/설치/다운로드) | 도구 목록 | 덧붙임(UX-007 0장 표: 목록 배지). KRDS badge 부품 | 유지(덧붙임 근거) |
| 사용 기록 단추 | 저장소 상단 맨 끝 | 덧붙임(UX-007 0장 표) | 유지 |
| 파일 보기 막대의 보기 전환 상자(미리보기/코드/Blame) | CodeView | GitHub Preview/Code/Blame 버튼 묶음 | 유지 |
| 목록 상자(테두리 안 행) | 이슈/MR/커밋/태그/브랜치 | GitHub, 공공 깃랩 목록 상자 | 유지 |
| 로그인 흰 판(행안부 로고) | 로그인 왼쪽 | 사용자 지시로 판 금지 | 이미 제거(MoisLogo 인라인, 바탕 그대로) |

## 남은 확인
- 브라우저로 다시 열어 각 화면에서 위 요소가 사라졌는지 스크린샷으로 확인
- `.rb-pill`을 쓰는 화면 전수(P18, P19, P20, 상단, 정보 영역, DiffView 새 파일/삭제/이름 변경 표시)가 모두 GitHub/GitLab에 대응이 있음. 그 밖에 새로 만든 알약은 코드에 없다
