# UX-015 정답 카드 양식 (M-01 정확도 측정용)

- 작성: 2026. 10. 30.
- 용도: AI 소개 카드의 정확도를 팀이 만든 정답 카드 50개와 대조한다(PRD M-01). 정답은 팀이 README를 직접 읽고 채운다. AI 결과를 보지 않고 채운다
- 표본: data/cards/_gold_sample.json (분야별 비례 50개, README 있는 프로젝트만, 고정 시드)
- 칸은 카드 스키마(data/cards/schema.json)와 같다. 원문에 없으면 값은 `없음`(화면 '미기재')으로 적는다. 지어내지 않는다

## 작성 규칙
1. README 원문을 읽고 칸마다 근거 줄 번호(예: 12-18)를 함께 적는다
2. 하는 일은 쉬운 말 한 줄, 60자 안팎
3. 업무 분야는 data/cards/taxonomy.json의 통합 분야 이름 1~2개
4. 실행 형태는 `바로 열림`, `내려받아 실행(exe)`, `설치 필요(파이썬 등)`, `확인 필요` 중 하나
5. 보안 파일(.env 등)은 쓰지 않는다

## 채점 방법(제안, 팀 확정 필요)
- 칸마다 일치(1), 부분 일치(0.5), 불일치(0)를 두 사람이 따로 매기고 다르면 합의한다
- 규칙 칸(실행 형태, 이용 조건, README 상태, 기준 날짜, 만든 곳, 갱신일, 기술 구성)과 AI 칸(하는 일, 대상 업무, 분야, 실행 방법, 한계)을 나눠 센다
