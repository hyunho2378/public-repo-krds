# 어돌잘돌

**여러 곳을 방문하는 소방 출장, 어디부터 가면 좋을까요?**

어돌잘돌은 소방서·119안전센터·소방용수시설 등을 방문할 때 출장 경로를 계획하는 웹앱입니다. 갈 곳과 차량별 출발·도착지만 선택하면 실제 도로를 기준으로 방문 순서와 경로를 추천하고, 예상 시간·이동 거리·통행료를 보여줍니다. PC와 휴대폰에서 웹브라우저로 이용할 수 있습니다.

**[웹앱 바로 이용하기](https://fireroute.xogns1526.chatgpt.site/)** · 제작자: **창원소방본부 오태훈**

## 이런 출장에 활용할 수 있어요

- 여러 119안전센터를 방문할 때, 어느 곳부터 들를지 계획합니다.
- 소화전·급수탑·저수조·비상소화장치를 점검할 때, 관할과 시설 종류로 방문 대상을 찾습니다.
- 여러 차량이 함께 출장할 때, 차량별 방문 대상과 출발·도착지를 구성합니다.
- 자주 쓰는 출장 구성을 즐겨찾기에 저장하고 다음에 다시 불러옵니다.

예를 들어 **마산소방서에서 출발해 안전센터와 용수시설을 방문한 뒤 돌아오는 출장**이라면, 방문 대상을 선택하고 출발·도착지를 마산소방서로 정한 다음 ‘추천 경로 찾기’를 누르면 됩니다.

## 이용 순서

1. **갈 곳 찾기:** 소방기관을 검색하거나 소방용수시설등에서 관할·종류를 선택합니다. 주소나 좌표로 직접 추가할 수도 있습니다.
2. **차량 설정:** 차량별 출발·도착지를 정합니다. 출장지는 한 번에 최대 30곳까지 선택할 수 있습니다.
3. **경로 기준 선택:** ‘시간 우선’ 또는 ‘거리 우선’을 선택하고, 유료도로 허용 여부를 정합니다.
4. **추천 결과 확인:** 지도와 예상 시간·거리·통행료를 확인합니다. 방문 순서나 차량 배정을 바꾸고 다시 조회할 수도 있습니다.

‘무료도로 안내’는 통행료가 0원으로 확인된 경로만 안내합니다. 조건에 맞는 경로를 찾지 못하면 안내 메시지를 표시합니다.

## 현재 개발 상태

핵심 기능 구현과 시범운영 배포를 완료했고, 데이터 보완과 현장 사용 검증을 진행 중입니다. 2026년 창원 조사자료를 반영하여 창원 관할의 소방용수시설과 비상소화장치를 함께 조회합니다.

- 기관·시설 검색, 실제 도로 경로 조회, 차량·방문 순서 편집, 즐겨찾기와 작업 복원을 지원합니다.
- 주소·좌표 검색을 지원합니다. 장소명 검색은 별도의 API 설정이 필요하며 현재 주소 검색 안내로 대체합니다.
- 일부 위치는 추가 확인이 필요합니다. 평일 자동 데이터 갱신 예약은 별도 운영 작업입니다.
- 출장용 일반 승용차 기준의 참고 경로입니다. 소방차의 긴급 출동 경로를 안내하는 용도는 아닙니다.
