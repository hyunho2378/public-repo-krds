# 엑셀 좌표-KML 변환 도구

[공공행정] 엑셀에 적힌 좌표를 지도에서 볼 수 있는 KML로 바꿔 주는 도구입니다.

고시문과 설계도면에는 좌표가 표로만 적혀 있습니다. 그 숫자가 어디를 가리키는지 보려면 한 점씩 지도에 찍어야 합니다. 점이 서른 개만 돼도 한나절이 갑니다. 이 도구는 표를 그대로 읽어 KML 한 장을 만듭니다. 구글 어스에서 열면 바로 보입니다.

```mermaid
flowchart LR
    A["고시문 · 설계도면의<br/>좌표표"] --> B["엑셀에 옮겨 적기<br/>위도 · 경도 또는 TM"]
    B --> C["이 도구"]
    C --> D["KML"]
    D --> E["구글 어스에서<br/>자리 확인"]
    style C fill:#1565C0,color:#fff
```

**함께 쓰는 도구** — 반대 방향은 [KML-엑셀 변환 도구](https://gitlab.aigov.go.kr/park613/kml-to-excel)가 합니다. 지도에 찍어 둔 좌표를 엑셀 표로 옮겨 줍니다.

## 엑셀에 무엇이 있어야 하는가

**위도와 경도, 두 칸이면 됩니다.** 이름 칸이 있으면 도형 이름이 됩니다.

```
이름      | 모양    | 순번 | 위도         | 경도
예시 구역 | 폴리곤  | 1/4  | 37-24-00.00  | 126-30-00.00
예시 구역 | 폴리곤  | 2/4  | 37-24-18.00  | 126-30-36.00
```

좌표는 어느 쪽으로 적어도 읽습니다. 고시문에서 옮겨 적은 그대로 두셔도 됩니다.

| 적는 방법 | 보기 |
| --- | --- |
| 도 | `37.4` / `126.5` |
| 도분초 | `37-24-00.00` / `126-30-00.00` |
| 기호 | `37° 24' 00.00"` / `126° 30' 00.00"` |
| 평면직각좌표 | `TM X(N)`, `TM Y(E)` 와 `원점` 칸 |

도면 좌표를 넣으실 때는 원점 칸에 서부·중부·동부·동해 가운데 하나를 적으십시오. 세계측지계 기준으로 경위도를 되돌려 씁니다.

## 도형을 어떻게 나누는가

**모양** 칸에 포인트·경로·폴리곤을 적으면 그대로 그립니다. 칸이 없으면 점이 하나일 때는 포인트, 여럿이면 경로로 봅니다.

**이름이 바뀌거나 순번이 1로 돌아가면** 다른 도형으로 나눕니다. 한 표에 구역 여러 개를 이어 적으셔도 됩니다.

## 표에 적힌 좌표가 지도가 됩니다

고시문이나 설계도면의 좌표표가 실제로 어디를 가리키는지 눈으로 확인할 때 씁니다. 도·도분초·기호·평면좌표 어느 쪽으로 적혀 있어도 알아봅니다.

## 설치 없이 쓰기 (컴퓨터를 잘 모르셔도 됩니다)

파이썬을 설치하지 않고 쓰는 방법이 있습니다. 저장소의 **릴리스(Releases)** 에서 `엑셀 좌표-KML 변환 도구(설치 없이 쓰는 묶음).zip` 을 내려받으십시오. 파이썬이 그 안에 들어 있어 여러분 컴퓨터에는 아무것도 깔리지 않습니다.

**[⬇ 묶음 내려받기 — 릴리스 페이지](https://gitlab.aigov.go.kr/park613/excel-coords-to-kml/-/releases)** — 가장 최근 묶음이 맨 위에 있습니다.

```mermaid
flowchart LR
    A["릴리스에서<br/>zip 내려받기"] --> B["압축 풀기"]
    B --> C["input 폴더에<br/>엑셀 넣기"]
    C --> D["실행하기.bat<br/>두 번 누르기"]
    D --> E["output 폴더에<br/>KML"]
    style D fill:#C62828,color:#fff
```

1. 내려받은 압축 파일을 **오른쪽 버튼 → 압축 풀기** 로 풉니다. 바탕화면처럼 찾기 쉬운 곳이 좋습니다.
2. 풀린 폴더를 열면 `★ 먼저 읽어보세요.html` 가 맨 위에 있습니다. 두 번 누르면 인터넷 창으로 열립니다. 쓰는 차례를 그림으로 그려 두었고, 넣을 파일의 서식과 자주 막히는 곳까지 그 한 장에 담았습니다.
3. `input` 폴더에 바꿀 파일을 넣습니다.
4. `실행하기.bat` 을 두 번 누릅니다. 검은 창이 뜨고 진행 상황이 지나갑니다.
5. "엔터를 누르면 창이 닫힙니다" 가 나오면 엔터를 누릅니다.
6. `output` 폴더를 열면 결과가 들어 있습니다.

처음 실행할 때 **"Windows의 PC 보호"** 라는 파란 창이 뜰 수 있습니다. 인터넷에서 받은 파일이라 한 번 묻는 것입니다. **추가 정보** 를 누른 다음 **실행** 을 누르시면 됩니다. 다음부터는 묻지 않습니다.

폴더를 통째로 옮기거나 USB에 담아 다른 컴퓨터에서 쓰셔도 됩니다. 지우실 때는 폴더를 삭제하면 그만입니다. 레지스트리나 프로그램 목록에 남는 것이 없습니다.

> 파이썬을 이미 쓰고 계시거나 명령창이 익숙하시면 아래의 본래 방법이 더 가볍습니다. 묶음은 파이썬 본체까지 담고 있어 11MB쯤 됩니다.

## 쓰는 법

처음 한 번만 필요한 꾸러미를 받습니다.

```
pip install openpyxl
```

### 더블클릭으로 쓰기 (명령창을 모르셔도 됩니다)

1. 좌표가 적힌 엑셀을 `input` 폴더에 넣습니다.
2. `엑셀 좌표-KML 변환 도구.py` 를 더블클릭합니다.
3. `output` 폴더에 같은 이름의 KML이 생깁니다.

구글 어스에서 그 파일을 열면 점과 구역이 지도 위에 그려집니다. 자리가 엉뚱하면 위도와 경도가 바뀌어 적혔거나 원점이 틀린 경우가 대부분입니다.

### 명령창으로 쓰기

```
python "엑셀 좌표-KML 변환 도구.py" 표.xlsx
python "엑셀 좌표-KML 변환 도구.py" 폴더 --out 결과폴더
```

## 잘못 적힌 좌표 알림

우리나라 밖으로 나간 좌표가 있으면 몇 개인지 알려 줍니다. 위도와 경도를 바꿔 적는 실수가 가장 흔합니다.

## 저장소에 포함하지 않는 것

실제 자료와 만들어진 KML은 담지 않습니다. 서식을 보실 수 있도록 가상의 좌표로 만든 예시 엑셀만 넣어 두었습니다.
