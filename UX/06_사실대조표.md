## 4. 처리 규칙
- **실제**: 받아 둔 응답이나 원문에서 그대로 가져온 값
- **예시**: 자료가 없어 임시로 넣은 값. 프레임 이름 끝에 `(예시 자료)`를 붙이고 프레임 밖 주석에 이유를 적는다
- **설계**: 우리가 새로 정한 문구나 구성. 사실 주장과 무관하다
- 자료가 없는 화면은 빈 상태(Empty)를 대표 변형으로 둔다(A-05, G-06, G-07)

## 5. 남은 확인
- 파일별 마지막 변경 내용: 경로별 마지막 커밋을 받는 방법을 정하고 반영한다
- 사용 언어 비율: languages.json 실제 값을 R-25에 반영한다
- 멤버와 라벨: 공개 API로 받을 수 없으면 예시 표기를 유지한다
- 커밋 1,482회: API 전체 수 헤더가 없어 화면 캡처값을 쓴다. 코드에서는 받은 목록 수(100)와 다르므로 표기 방법을 통일한다
