- 문서 번호: UX-002
- 작성일: 2026. 10. 30.
- 상태: 초안
- 기준: UX-001 퍼소나 P1(찾아 쓰는 공무원), P2(만들어 올리는 공무원), UX 원칙 U1~U10, PRD-001 기능과 화면 목록

## 1. 전체 구조

### 1.1 머리글 주 메뉴(KRDS 헤더, 메인 메뉴)
| 순서 | 메뉴 | 하위 | 화면 | 로그인 |
|---|---|---|---|---|
| 1 | 도구 찾기 | 검색, 분야별, 기관별 | P-01 P-02 P-03 P-11 | 필요 없음 |
| 2 | 요청 보드 | 필요한 도구 요청, 공감 | P-15 | 보기는 필요 없음, 요청과 공감은 필요 |
| 3 | 도구 올리기 | 공개 준비 점검, 새 프로젝트 | P-09 | 필요 |
| 4 | 도움말 | 처음 쓰는 분, 자주 묻는 질문, 공지 | P-14 | 필요 없음 |
- 유틸리티 영역: 화면 모드(밝은 화면, 어두운 화면, 선명한 화면 모드, 시스템 설정 따르기), 로그인 또는 내 프로젝트
- 점검 공지는 모든 화면 머리글 위 KRDS 공지 배너로 보인다(불편 15)

## 2. 과업 흐름

### 2.1 과업 A 업무에 쓸 도구 찾기(P1, 핵심 흐름)
| 단계 | 공무원이 하는 일 | 화면 | 화면이 주는 것 | 실패와 대응 |
|---|---|---|---|---|
| 1 | 사이트에 들어온다 | P-01 | 로그인 없이 검색창과 분야 바로가기 | 점검 중이면 P-13 점검 |
| 2 | "출장비 정산 엑셀"처럼 업무를 문장으로 쓴다 | P-01 → P-02 | 결과 목록, 각 결과에 하는 일 한 줄, 실행 환경, 써 본 기관 수 | 결과 없음: 비슷한 말 제안, 요청 보드로 이어짐(P-15) |
| 3 | 조건으로 줄인다 | P-02 | 분야, 기관, 실행 환경, 갱신일 필터. 주소에 남음 | 필터 결과 없음: 필터 하나씩 해제 버튼 |
| 4 | 하나를 열어 써도 되는지 본다 | P-04 | 소개 카드와 판단 정보 영역 | README 없음: 카드 칸 비움 표시와 "제작자에게 요청" |
| 5 | 쓰기로 하고 실행 방법을 본다 | P-07 | 내 PC 환경 선택 → 가능 여부와 단계 안내 | 업무망 불가: 이유와 대안(웹 버전, 담당 부서 문의) |
| 6 | 써 본 뒤 기록과 의견을 남긴다 | P-04, P-08 | 써 봤어요 버튼, 의견 양식 선택 | 로그인 필요: 이유 안내 후 P-12, 끝나면 원래 화면으로 복귀 |

### 2.2 과업 B 만든 도구 올리기(P2)
| 단계 | 하는 일 | 화면 | 화면이 주는 것 | 실패와 대응 |
|---|---|---|---|---|
| 1 | 도구 올리기를 누른다 | P-09 | 로그인 확인, 올리기 전 확인 3가지(비슷한 도구, 보안 파일, 설명) | 미로그인: P-12 |
| 2 | 도구 이름과 하는 일을 쓴다 | P-09 | 비슷한 기존 도구 목록(F-04)과 만든 사람 연결(F-05) | 같은 도구 있음: 기존 도구에 의견 남기기 선택지 |
| 3 | 파일을 올리고 점검한다 | P-09 | 공개 준비 점검(F-21). 보안 파일은 공개 전 차단(F-22) | 보안 파일 발견: 공개 버튼 비활성, 제거 방법 안내 |
| 4 | 소개 카드를 확인한다 | P-09 | AI가 만든 소개 카드 초안 수정(F-11) | 분야 미선택: 추천 분야 제시 |
| 5 | 공개한다 | P-10 | 내 프로젝트에 추가, 의견 알림 | |

### 2.3 과업 C 받은 의견 처리(P2)
- P-10 내 프로젝트 → 받은 의견 수, README 개선 제안(F-23), 보안 알림(비공개) → P-08 해당 의견

### 2.4 과업 D 필요한 도구 요청(P1)
- P-02 결과 없음 또는 P-15 → 요청 쓰기(업무, 지금 하는 방법, 기대) → 공감 수 표시

## 3. 오류와 예외(U6)
| 상황 | 현재 | 바꿈 |
|---|---|---|
| 없는 주소 | 로그인 화면으로 이동, 영어 안내 | P-13 찾을 수 없음. 검색창과 첫 화면 버튼 |
| 권한 없음(비공개 프로젝트) | 로그인 화면으로 이동 | P-13 권한 없음. 로그인하면 볼 수 있는지 여부와 만든 기관 문의 방법 |
| 점검 | 로그인 화면에만 공지 | 모든 화면 공지 배너, 점검 중에는 P-13 점검 |
| 로그인 필요 행동 | 바로 로그인 화면 | 행동 이름과 로그인 이유를 쓴 안내 후 이동, 완료 뒤 복귀 |

## 4. 화면별 KRDS 부품과 패턴
| 화면 | KRDS 패턴 | 주요 부품 |
|---|---|---|
| P-01 | 기본 패턴 검색 | 헤더, 공지 배너, 검색창, 바로가기 링크 목록, 푸터 |
| P-02 | 기본 패턴 검색, 필터 | 검색창, 체크박스, 선택 칩, 구조화 목록, 페이지네이션 |
| P-03 | 기본 패턴 목록 | 탭, 구조화 목록, 배지 |
| P-04 | 상세 정보 | 브레드크럼, 탭, 설명 목록, 배지, 버튼, 정보 요약 |
| P-05 | 상세 정보 | 탭, 표, 아코디언(개발자용 정보) |
| P-06 | 상세 정보 | 단계 표시기 없음, 구조화 목록, 날짜 |
| P-07 | 서비스 패턴 신청 단계 | 라디오(환경 선택), 단계 표시기, 안내 문구, 코드 블록 대신 버튼 |
| P-08 | 서비스 패턴 입력 | 라디오 카드(양식 선택), 입력칸, 텍스트 영역, 파일 첨부 |
| P-09 | 서비스 패턴 신청 단계, 확인 | 단계 표시기, 입력칸, 체크 결과 목록, 알림 메시지 |
| P-10 | 기본 패턴 목록 | 탭, 구조화 목록, 배지 |
| P-11 | 기본 패턴 목록 | 검색창, 구조화 목록 |
| P-12 | 서비스 패턴 로그인 | 로그인 템플릿 그대로 |
| P-13 | 기본 패턴 오류 | 오류 템플릿 |
| P-14 | 기본 패턴 도움 | 아코디언, 사이드 메뉴 |
| P-15 | 기본 패턴 목록과 입력 | 구조화 목록, 버튼, 텍스트 영역 |
