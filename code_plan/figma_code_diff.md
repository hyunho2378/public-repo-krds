# Figma와 코드 차이 목록(내 범위: P-01, 02, 03, 09~15)

- 작성: 2026. 10. 30. Figma 화면 갈래
- 대조 방법: 코드(app, 서버 5792, 화면 5791)를 1920과 360으로 캡처해 Figma 프레임과 나란히 비교
- 원칙: 문구는 ko.js가 기준(Figma를 ko.js에 맞춤 완료). 간격과 배치는 Figma 기준으로 정하고 코드가 맞춘다
- 결정 필요 표시가 있는 항목은 부모 갈래가 사용자에게 확인

## 1. 코드가 Figma에 맞출 것
| 번호 | 화면 | 코드 지금 | Figma 기준 |
|---|---|---|---|
| C1 | 공통 머리글 | 로그인, 내 프로젝트가 아이콘 위, 글자 아래 두 줄 | KRDS header_menu 원본처럼 아이콘 왼쪽, 글자 오른쪽 한 줄 |
| C2 | 공통 주 메뉴 | 펼침 표시(꺾쇠) 없음, 현재 메뉴 밑줄 | KRDS main_menu 원본: 1뎁스마다 꺾쇠, 선택 상태는 KRDS selected 변형 |
| C3 | 공통 360, 768 | 하단 탭바 없음, 머리에 로그인과 전체메뉴 | D-03 앱형: KRDS tab_bars__mo 하단 고정(홈, 찾기, 알림, 내 프로젝트). 알림 아이콘은 KRDS에 종 모양이 없어 icon/system-info |
| C4 | P-01, P-02 360 | 검색 입력칸 높이가 눌려 글자가 잘림 | 입력칸 KRDS large 높이 그대로, 아래에 전체 폭 검색 버튼 |
| C5 | P-01 제목, 안내문 | "도구를찾아보세요", "전에다른", "확인하세요.로그인"처럼 덩어리 사이 띄어쓰기가 사라짐 | 덩어리(" \| ") 사이 공백 유지. K1~K5 |
| C6 | 목록(구조화 목록) | 테두리 없는 채운 면 상자, 항목 사이 간격 좁음 | KRDS structured_list card 원본 면과 테두리, 항목 사이 gap/3 |
| C7 | 목록 설명 | 길면 3줄 이상 | 2줄 말줄임(…) |
| C8 | 목록 기관 칸 | 기관이 개인 이름이면 그대로 노출(예: "순형 권") | U9: 기관으로 확인되지 않으면 "기관 확인 필요" |
| C9 | P-01 360 분야 바로가기 | 3열 감싸기 | Figma도 360에서 감싸기로 맞춤(코드 유지) |

| C11 | P-04 사용 기록 입력 | 레이블 "사용한 기관", "사용한 날짜" | "(필수)" 표시. ReuseAction_3, _4 (저장소 갈래 화면이지만 문구 키는 공통) |
| C12 | 점검 결과 배지 | krds-badge small | KRDS badge solid-pastel medium, 있음 = success, 보완 필요 = warning. 행마다 아래 구분선(divider gray-light) |

## 2. 결정 필요(부모 갈래, 사용자 확인)
